   - Privacy Policy: `GET /api/policies/privacy`

   - Refund Policy: `GET /api/policies/return`
   - Shipping Policy: `GET /api/policies/shipping`

2. **Response Format:**
   The backend should return JSON in this format:
   ```json
   {
     "success": true,
     "message": "Policy retrieved successfully",
     "data": {
       "type": "privacy",
       "content": "<HTML_CONTENT_HERE>",
       "lastUpdated": "2025-11-07"
     }
   }
   ```

3. **HTML Formatting:**
   - All email addresses should use the `email-link` class for proper styling
   - Use proper HTML heading hierarchy (h1, h2, h3, h4)
   - Tables should be properly formatted
   - Lists should use `<ul>` and `<li>` tags

4. **Email Links:**
   All email addresses in the content should be clickable links with the format:
   ```html
   <a href="mailto:email@thebabyland.in" class="email-link">email@thebabyland.in</a>
   ```

5. **Last Updated Date:**
   Ensure the "Last Updated" date is maintained in the database and displayed in the response.
