Project  Overview  Babyland  is  a  maternal  &  child  health  Flutter  app  that  covers  three  life  stages:  
Stage  Description  
Pre-Pregnancy  
Menstrual  cycle  tracking,  daily  logs,  AI  insights,  cycle  calendar  

Pregnancy  Pregnancy  dashboard,  fetal  development,  appointments,  save  logs,  community  
Post-Pregnancy  
Baby  details,  baby  growth  (milestones,  photos,  vaccinations),  recovery  tracking,  feeding  logs  
The  app  also  includes  Expert  Consultation  (doctor  listing,  slot  booking,  video  calling  via  Agora),

Authentication  Email/Password  Flow  
1.  Sign  Up:  request-verification →  OTP  →  verification →  set-password →  onboarding/complete  2.  Sign  In:  login-with-password →  token  saved  to  SecureStorage  3.  Forgot  Password:  request-forget-password →  OTP  verify  →  set-password  

Managed  by  controllers  in  lib/app/controller/sign_in/,  create_account/,  forgot_password/.  
Google  Sign-In  Flow  File:  lib/app/services/social_login/social_login.dart  
●  Singleton  SocialLoginService  ●  Uses  google_sign_in +  firebase_auth  ●  Reads  SERVERClientID from  .env  (Web  client  ID  from  Google  Cloud  Console)  ●  Sign-out  before  sign-in  to  always  show  account  picker  ●  Uses  authenticate(scopeHint:  ['email']) (Credential  Manager  API)  ●  On  success  →  Firebase  credential  exchange  →  navigates  to  stagesView  ●  Error  handling  for  API  Exception  10,  sign-in  canceled  
Token  Injection  Auth  token  is  automatically  attached  to  every  API  request  via  Dio  interceptor  in  NetworkApiServices.
